# Classic Display Checklist - Separate Ask and Try
v3-0.1.28-controls

[Download the printable PDF](CLASSIC-DISPLAY-CHECKLIST.pdf). Page numbers below refer to that PDF.
This reference matches the exact Classic text in `v3-0.1.28-controls`; Ask and Try are independent shuffled decks.


## Two separate sections

ASK: pages 2-13. TRY: pages 14-25. Each page contains one mode only: its main-screen wording and its matching Guide me text. Ask and Try have independent shuffled decks. They are not a pair to step through together, and neither section is a prescribed draw order.

## Choose your section

From the Classic compass, tap its centre. Choose Ask the Team to test the ASK section, or Try a Move to test the TRY section. Shaking, flipping and Another draw within the selected mode; they do not switch between Ask and Try.

## Check one displayed card

1. Wait for the current message and controls to become visible.
2. Tap Guide me. Read the title at the start of the guidance.
3. Find that title in the section for the mode you selected.
4. Compare the complete Guide me wording, scrolling or using More text if needed.
5. Tap Back. Compare the main-screen wording on the same PDF page. It should return to the same message.
6. Mark the checks. Use Another to draw another card in that mode.

## What the page headings mean

ASK CARD, TRY CARD, title and ID are document lookup labels. They do not mean those headings are painted on the current main screen. Guide me does show the card title. Only the two expected-wording blocks reproduce display text. Line breaks can differ from the round screen.

## Finish one mode, then the other

Tick off all 12 titles in the mode you are testing. Then choose the other mode from the compass menu and use its separate section. If you began part-way through a shuffled deck, repeats may occur before your checklist is complete; do not assume exactly 12 draws are enough. No firmware change or restart is needed for this content check.

## Report a mismatch

Record the selected mode, the Guide me title and what differs. A photo of the main screen and Guide is useful. Check wording, complete scrolling access and Back restoring the same card. This is not a gesture-reliability test, and it does not alter the draft status of the authored cards.

# TRY CARD - FOG AHEAD (tg-002)

## Main screen - expected wording

Ask AI to ask you one clarifying question at a time.

## Guide me - expected wording

FOG AHEAD

How to run it
Give a short, non-sensitive challenge description. Answer up to three clarifying questions, one at a time. Stop and rewrite the challenge using what changed; do not let questioning replace action.

What to notice
Whether the questions change the team's understanding. Stop when enough is clear to take a useful step; more questions are not always better.

You could ask
What became clearer?

What can you try with what you know now?

If helpful, offer
Would one clarifying question at a time help?

# TRY CARD - SCOUT (tg-001)

## Main screen - expected wording

Ask AI for three very different approaches.

## Guide me - expected wording

SCOUT

How to run it
Name the current approach. Ask for three alternatives with different starting assumptions, then choose one difference worth exploring. Do not select a winner yet.

What to notice
A useful difference between the options. The team can reject AI suggestions or decide not to use AI.

You could ask
Which difference is worth exploring next?

What would you want to learn before choosing?

If helpful, offer
Would it help to explore three different approaches?

# TRY CARD - SMALL STEPS (tg-004)

## Main screen - expected wording

Ask AI for a test you can finish in ten minutes.

## Guide me - expected wording

SMALL STEPS

How to run it
Choose one uncertain assumption. Define a reversible test with an observable result and a stop condition. Use synthetic or approved material, run the test, and record what it did and did not show.

What to notice
An actual observation, a safe stopping point and the limits of the test. Finishing a test does not prove the whole idea works.

You could ask
What did you observe?

What can you conclude, and what remains uncertain?

If helpful, offer
Would a small, safe test help you learn more?

# TRY CARD - CHECK BEARINGS (tg-003)

## Main screen - expected wording

Which claims need checking? Verify one independently.

## Guide me - expected wording

CHECK BEARINGS

How to run it
Select one consequential factual claim. Use AI or tools if helpful to check original sources, direct observations or trusted references. Look for actual evidence, not model agreement. If you cannot check it now, label it unverified and do not use it to justify a risky action.

What to notice
An original source, direct observation or trusted reference. A repeated AI answer is not an independent check. Unavailable checks leave a claim unverified.

You could ask
What did the check establish?

What remains unverified?

If helpful, offer
Would it help to check one claim together?

# TRY CARD - MAKE CAMP (tg-011)

## Main screen - expected wording

Summarize progress, open questions, and the next step.

## Guide me - expected wording

MAKE CAMP

How to run it
Say or write three bullets: progress supported by evidence, open questions and the next concrete action. Name an owner for the next action with their agreement. Keep private discussion out of shared summaries.

What to notice
Whether the summary separates observed progress from open questions. A proposed next action needs an owner's agreement; do not infer it from silence.

You could ask
Does this summary match what happened?

What is the next useful step?

If helpful, offer
Would a short progress-and-next-step summary help?

# TRY CARD - NAME THE BLOCKER (tg-028)

## Main screen - expected wording

Decide whether you lack information, a decision or a workable next action.

## Guide me - expected wording

NAME THE BLOCKER

How to run it
Each person may name the blocker. Agree whether the next move is to obtain information, ask a decision-maker or reduce the task. Pick one action that addresses that blocker instead of generating more ideas.

What to notice
Whether the team identifies information, a decision or an actionable step it needs. Several blockers may coexist; choosing one need not dismiss the others.

You could ask
Which blocker should you address first?

What action would address that blocker?

If helpful, offer
Would it help to name the blocker before making more ideas?

# TRY CARD - QUIET FIRST (tg-031)

## Main screen - expected wording

Give everyone quiet thinking time before discussion or AI suggestions.

## Guide me - expected wording

QUIET FIRST

How to run it
Allow one minute for private thinking, writing or drawing. Invite sharing without requiring it, then group contributions before asking AI. Offer a spoken or paired alternative for anyone who prefers it.

What to notice
Room to think independently and accessible ways to contribute. Sharing is optional; accept passing without asking people to justify it.

You could ask
What would anyone like to share, or pass on?

What distinct ideas should the team keep in view?

If helpful, offer
Would a quiet minute before sharing help?

# TRY CARD - CHOOSE THE COMPASS (tg-036)

## Main screen - expected wording

Agree on two criteria before comparing options.

## Guide me - expected wording

CHOOSE THE COMPASS

How to run it
Name two criteria linked to the team's outcome. Separate mandatory safety or policy constraints from preferences. Compare options using available evidence and leave unknowns visible instead of inventing scores.

What to notice
Criteria the team actually agreed to and evidence relevant to them. Unknowns should stay visible rather than becoming invented scores.

You could ask
How do the options compare on those criteria?

What is still unknown before you choose?

If helpful, offer
Would agreeing on two criteria help you compare options?

## Main screen - expected wording

Ask AI for the strongest argument against your plan.

## Guide me - expected wording

CHANGE COURSE

How to run it
Describe the plan and ask for a substantive objection, not an attack on people. Identify which concern has evidence and which is hypothetical. Choose whether it calls for a change or a test.

What to notice
Distinguish evidence from assumptions. An objection need not mean the plan should change.

You could ask
Does this call for a change, a test, or no change?

If helpful, offer
Would it help to explore a good-faith objection?

# TRY CARD - HUMAN FIRST (tg-014)

## Main screen - expected wording

Sketch how to solve the problem without AI. Keeping that approach is a complete choice.

## Guide me - expected wording

HUMAN FIRST

How to run it
Draw a three-step human-only workflow. Keeping it is a complete choice. If useful, compare a limited AI-assisted or hybrid option, including preparation, checking, corrections and learning value. Keep accountable human judgment visible; do not assume AI adds value.

What to notice
Keeping the human-only approach is complete. Any comparison with AI is optional and includes checking and learning value.

You could ask
What would you keep about this approach?

If helpful, offer
Would it help to sketch a human-only approach?

KEEP OR ADAPT

# Coaching display guide

## Start

From the Classic compass, tap the centre, then Coaching. Choose Progress, Stuck, Unclear, Explore, AI or Team. An opening question is optional: tap the Coaching compass centre, then Another opener.

## Questions and tries

Paths changes context. Another cycles through questions or experiments in the current path. Try (optional) switches to experiments; Question switches back. Each path remembers its question and experiment separately.

## Guide me

Guide me opens guidance for the current entry. Back returns to where you came from. For an opening card, use Options > Guide me. Guide also offers Release, Opening and Reminders.

## Finishing and reminders

Release opens the closing prompts. Options > Reminders opens the listening reminders. Both screens offer Back, Release, Opening and Next. Next cycles within that group; Opening returns to the Coaching compass. These screens have no Guide me.

## Options

Tap the compass centre, or Options on an opening card. The menu has Back, Another opener, Guide me, Release, Classic, Instant ON/OFF, Reminders and Sound ON/OFF. Classic changes mode; Instant skips the opening animation but not its reading hold; Sound controls the optional cue.

## Scrolling and motion

Scroll when Scroll for full text appears. S arms a temporary shake request; tapping S does not draw a card. Accepted shakes or flips draw an opener, not the next question. Coaching automatic-shake reliability remains unresolved; use the touch controls when needed.

## About the entries

Each following page contains the unchanged screen text and, where available, its Guide me text. Page headings help you browse; they are not extra screen text. Version 31. Content remains DRAFT.

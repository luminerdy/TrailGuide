# Coaching display guide

## Scope and reading key

DRAFT | version 31. This is a screen-text and navigation reference, not new coaching copy or a change to startup. Classic remains the boot mode. Enter Coaching from the Classic compass: tap the compass centre, then Coaching. Coaching opens its compass, with the opener hidden. You may choose a path directly; an opener, a fixed number of questions and an experiment are not prerequisites.

## Six contexts, not six activities

The compass buttons, clockwise from the top, read Progress, Stuck, Unclear, Explore, AI and Team. The corresponding path headings on Question, Experiment and path Guide screens read Progress, Stuck, Unclear, Exploring, AI Results and Team. The wandering compass arrow is decorative; the user chooses the path.

## How this book is arranged

Each authored entry has its own page, in generated source order: openers, path questions, path experiments, closings, reminders. Main text and its matching Guide me wording stay together; Question and Experiment entries are separate pages. IDs, type headings and access instructions are document lookup aids, not text painted on the main screen. There is no question-to-experiment pairing by number: each path independently remembers its question and experiment.

# Compass, opening and options

## Compass and optional opening

On the Coaching compass, the six path buttons are visible. Its centre has an unlabelled Options target; there is no painted Options caption on that compass. Tapping it opens Options. Another opener draws an opener and leaves the compass view. The opening card has Options plus the same six path buttons; choose a path whenever useful. Options > Guide me shows the saved current opener guidance, including when the opener was hidden behind the compass.

## Options: visible labels and effects

Back returns to the saved prior view. Another opener selects a fresh opener from a shuffled opener pool (no immediate repeat across pool boundaries when more than one opener exists), clears back history and starts the new-card reveal. Guide me opens guidance for the current entry; from Options its Back first returns to Options. Release opens the first closing. Classic exits Coaching. Instant ON / Instant OFF toggles animated opening reveals; returning from a toggle uses the saved Options context. Reminders opens the first reminder. Sound ON / Sound OFF toggles the shared optional sound cue; it is not recording or speech. No accounts or persistent coaching history are added.

## Reveal, reading hold and complete text

A new opener draw normally reveals over six seconds, followed by a two-second reading hold with navigation hidden. Instant skips the animation, not the reading hold. A non-drag tap during reveal completes the same opener and begins the hold; a settled non-drag tap can expose controls early. Missing presentation resources may leave instant/full-copy access instead. Opening, Guide, Back, path changes and Another within a path do not start a fresh-opener animation. Scroll for full text appears only when text extends below the viewport; scroll the body to reach the complete copy.

## Motion and S

An accepted shake or flip starts fresh with another opener from any Coaching view, cancelling the prior reveal/hold and clearing back history; it is not Another within a path. Touch/scroll contact suppresses these actions. S is a manual shake-request button on a visible opening card and on Question/Experiment screens, not the compass or Guide. It arms a bounded eight-second shake request when eligible; Shake ready is the temporary status. It does not select a path, switch faces or draw on the tap alone. Navigation/contact/expiry cancels the request. Qualified inversion may temporarily blank the screen; a cancelling touch restores the prior scene without forwarding that same click.

# Path, Guide and finishing routes

## Question and Experiment controls

Both faces have Paths, Guide me and Release across the top. Question has Another and Try (optional) below; Experiment has Another and Question. Another cycles only the current path and current type in authored order, wrapping to its first entry. First use starts at Q01 or E01. Try (optional) restores that path's saved experiment (initially E01); Question restores its saved question. Switching does not pair entries by number, draw an opener, or push another back-history frame.

## Paths picker

Paths opens the six context buttons and the label Choose a path, plus Opening, Next step and Back. Back restores the prior face and scroll position. Choosing the current path returns to that face; choosing a different path restores that path's last Question/Experiment face and clears back history. Opening returns to the Coaching compass with the saved opener hidden and clears history. Next step opens the first closing; it does not advance a question quota.

## Guide me routes

Guide displays the current entry's guidance, not a newly drawn entry. A path Guide keeps the corresponding full path heading; opener Guide reads Guide me - optional. Visible controls are Back, Release, Opening and Reminders. Back restores its immediate origin (Question, Experiment or Options) and its saved scroll; Opening returns to the compass; Reminders opens the first reminder; Release opens the first closing. Guide is optional and does not consume Another. Nested returns use bounded RAM-only back history; a fresh opener or Opening clears it.

## Reminders and closing

Reminders is reached from Options or Guide. The screen heading is Private listening cues; Next cycles reminders in authored order and wraps. Release, or Next step in the path picker, opens CLOSE-01 with heading Next step - optional. Next cycles the three closings and wraps. Both kinds have Back, Release, Opening and Next. Back returns to the saved immediate origin; Opening returns to the compass. Release on an existing Closing leaves that closing unchanged. These screens do not offer Guide me; their stored guidance fields are empty. No final answer, experiment, recording or collected response is required.

## Saved state and access checklist

The model retains opener, per-path Question and Experiment positions, last face and scroll in RAM, not a persistent journal. Re-entering Coaching returns to its compass without forcing a new visible opener. [ ] Paths > Back restores the face. [ ] Guide me > Back preserves the message. [ ] Try (optional) > Question restores independent positions. [ ] Next wraps closings/reminders. [ ] Opening returns to compass. [ ] A fresh opener resets back history.
